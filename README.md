# 🥁 DrumRoll (ドラムロール)

> **音選びで迷わせない。思いついたグルーヴを最速で形にするポケットドラムマシン**

「ドラムロール（ﾃﾞﾚﾚﾚﾚ…）」と「ピアノロール」をかけた、ブラウザで動く簡易ドラム打ち込みWebアプリケーションです。

---

## ✨ 主な特長

1. **外部音源ファイル完全不要（即起動・容量ゼロ）**
   - Web Audio APIによる高品質シンセサイズ（808/909系のアナログドラムサウンド）
   - ネット環境がなくてもオフラインで動作し、音源の読み込み待ちがありません。

2. **🎵 厳選ドラムプリセット 8選 (即戦力パターン)**
   - **王道8ビート** (BPM 120) - ポップス・ロックに最適
   - **ダンス風** (BPM 128) - 4つ打ちEDM・クラブスタイル
   - **シティポップ** (BPM 105) - 16ビートのファンキーなノリ
   - **ヒップホップ** (BPM 140) - 3連符ハットロール入りのTrapビート
   - **ロック** (BPM 175) - 疾走感のあるパンク・ボカロ系2ビート
   - **シャッフル** (BPM 95) - 3連符でハネる心地よいスウィング
   - **ラテン風** (BPM 96) - レゲトン・Dembowのダンサブルなリズム
   - **ドラムロール** (BPM 125) - サビ前のタム回し＆ビルドアップ

3. **初めてでも安心！「❔ ガイド」機能**
   - 画面右上の「❔ ガイド」を押すと、主要な機能（再生、テンポ、ピアノロール、試聴、パッド、プリセット）から引き出し線が伸びて使い方が一目でわかります。
   - 画面サイズに応じて線が自動追従し、スマホでは1ステップずつのツアー形式に切り替わります。

4. **迷わない8点ドラム構成**
   - **Kick** (バスドラム / C1)
   - **Snare** (スネアドラム / D1)
   - **Clap** (ハンドクラップ / D#1)
   - **Closed Hat** (クローズハイハット / F#1)
   - **Open Hat** (オープンハイハット / A#1)
   - **Low Tom** (ロータム / A1)
   - **High Tom** (ハイタム / D2)
   - **Crash** (クラッシュシンバル / C#2)

3. **2つの入力モード**
   - **🎹 ピアノロールモード**：
     - DAW感覚でグリッドをクリック/タップしてノート配置・編集
     - トラック名をクリックしていつでも音色を試聴可能
     - タイムラインルーラーをクリックして再生位置ジャンプ
   - **⚡ リアルタイムモード**：
     - **スマホ**：直感的なタッチパッド（マルチタッチ対応）
     - **PC**：キーボード（ホームポジション）で両手タイピング演奏
     - 録音ボタンを押せば、叩いたリズムがそのままピアノロールにリアルタイム記録されます。

4. **本格エクスポート ＆ 簡単共有**
   - **🎼 MIDI書き出し (.mid)**：
     - Standard MIDI File (Format 0, ドラムCh.10) を出力。
     - Cubase, Logic, Studio One, FL Studio などのDAWにそのままドラッグ＆ドロップ可能！
   - **🔊 WAV書き出し (.wav)**：
     - ブラウザ内でオフラインレンダリングし、高音質16bit/44.1kHz WAVを即座に生成。
   - **🔗 URL共有**：
     - URLの末尾にビートデータを圧縮して埋め込み。URLを送るだけでスマホ⇄PC間での共有や友達への共有がアカウント不要で一瞬で完了します。
   - **💾 プロジェクトJSON保存 / 読み込み**：
     - バックアップやビートのストックに最適。

5. **制作をサポートするユーティリティ**
   - テンポ（BPM 40〜260）・拍子（4/4, 3/4）・小節数（1〜8小節）の変更
   - メトロノーム（アクセント付きクリック音）
   - クオンタイズ機能（録音後のヨレを1/16, 1/8等にピタッと吸着補正）
   - 自動保存（LocalStorage）でブラウザを閉じても前回の状態を保持

## ⌨️ 操作一覧

### PC操作
| 操作 | 動作 |
| :--- | :--- |
| **`Space`** | **再生 / 一時停止** (現在の位置から再生) |
| **`R`** | **リアルタイム録音 開始 / 停止** |
| **左クリック / タップ** | **ノート配置 / 既存ノートの消去** (直感的切り替え) |
| **右クリック / 右ドラッグ** | **消しゴム (連続消去)** |
| **`Ctrl + Z`** (Mac: `Cmd + Z`) | **元に戻す (Undo)** 直近20操作まで対応 |
| **`Ctrl + Y`** / **`Ctrl + Shift + Z`** | **やり直し (Redo)** |
| **`A` `S` `D` `F`** | **Kick / Snare / Clap / Closed Hat** (左手) |
| **`J` `K` `L` `;`** | **Open Hat / Low Tom / High Tom / Crash** (右手) |
| **通常マウスホイール** | **タイムライン左右スクロール** |
| **`Shift` ＋ マウスホイール** | **ズームイン / ズームアウト** (拡大・縮小) |
| **ツールバーの `🔍＋` `🔍−`** | **ズームイン / ズームアウト** |

### スマホ操作
| 操作 | 動作 |
| :--- | :--- |
| **パッドタップ** | 演奏＆リアルタイム録音 (マルチタッチ対応) |
| **1本指スワイプ** | タイムライン左右スクロール |
| **2本指ピンチイン / ピンチアウト** | **ズームイン / ズームアウト** (拡大・縮小) |
| **「⚡ パッド表示」/「−」** | パッドの折りたたみ・展開 |

## 🚀 起動方法

### Windows
フォルダ内にある `start.bat` をダブルクリックするだけで、自動的にローカルサーバーが立ち上がりブラウザで開きます。

### その他（Mac / Linux / 手動起動）
ターミナルを開き、以下のコマンドを実行してブラウザで `http://localhost:3000` にアクセスしてください。
```bash
python -m http.server 3000
```
または、`index.html` を直接ブラウザにドラッグ＆ドロップしても利用可能です。
